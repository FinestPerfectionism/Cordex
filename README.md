# Cordex
Cordex is a Discord bot tailored and designed specifically for the server "The Goobers" with moderation, utilities, and more Usage outside this server is not recommended. (See below.)
## Forking Notice
Forking this project for purposes other than direct contribution is highly discouraged. To make this bot usable for your own server, you will need to make major reforms across numerous undocumented files.
### Why?
There are minimal configuration options and many things are hardcoded, like roles, users, and channels.
## Built with...
* python 3.11
* discord.py 2.7.1
* basedpyright - All rules enabled
* ruff - All rules enabled
